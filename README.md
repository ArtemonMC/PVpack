# Eng:

PVPack is a modpack with all the essential mods you need to play on the **POLITMINE VANILLA** server.
**All mods included in the pack are allowed on the server, so you don't have to worry about getting banned.**

* Custom menu
* Performance optimization
* Voice Chat
* EmoteCraft
* Shader support
* High render distance with minimal performance impact

**This is a basic modpack and does not include additional visual mods, as they may not be everyone's cup of tea. You can always add them yourself.**

# Custom Menu & Performance Optimization

You can start playing with just one click, and the menu also contains all the useful links related to the project.

PVPack runs faster than vanilla Minecraft. The included mods provide a noticeable performance boost, helping the game run smoother even on lower-end devices.
